# Globe intelligence and geographic provenance

A globe record carries its approved geographic scope, publication or
measurement interval, source evidence, unit, basis and coverage status.
Areas carry the evidence. Optional selectable marker locations identify
representative labels for those areas.

| Layer | Visual semantics | Source status |
| --- | --- | --- |
| Network context | Neutral blue area with named metric | The current application has qualified Canadian CRTC LTE population coverage. Local V2 WDI/ITU has subscription data for 151 economies in 2024. It measures subscriptions per 100 people and preserves values over 100. |
| Inferred CVE reference | Purple dashed or hatched area with methodology | Requires a qualified aggregate CVE-to-network link and independent geographic evidence. Current NRO data are coarse registration totals. Individual ASN joins and positive CVE inference are unavailable. |
| Observed exposure | Amber area with observation period, unit and source | Needs authorized CVE-specific geographic measurements and redistribution rights. No qualified public observations are currently recorded. |
| Verified private site | Checkmark with workspace-restricted evidence | Requires authorized asset and site evidence. Exact locations remain private. |

Gray indicates unavailable evidence. A measured zero needs an explicit
valid source value. Red indicates severity and a star identifies a user
highlight. Registration geography describes a registry code. Operational
presence requires separate evidence. Annual subscription data and CRTC
population coverage retain separate units.

The planned map and timelines query one compatible release. Region drill-down
returns bounded observed or inferred CVE lists from evidence in that scope.
Network-only regions show available metrics and unavailable CVE geography.
The shared CVE selection then opens the same profile used by the graph and
catalog. Desktop resizable panes, mobile touch, fullscreen, keyboard
alternatives, context recovery and frame-rate acceptance remain pending.
